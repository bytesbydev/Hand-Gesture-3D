🚀 HOW TO USE THE NEW FEATURES
───────────────────────────────────────────────────────────────────────────────

1. SELECT 3D OBJECT:
   Use the dropdown in the header to choose between:
   • Cube (default)
   • Sphere
   • Torus
   • Pyramid

2. CONTROL GESTURES:
   • Move Hand → Move object in 3D space
   • Two Hands Close → Scale object smaller
   • Two Hands Apart → Scale object larger
   • Pinch Gesture → Grab object
   • Hand Rotation → Rotate object
   • Peace Sign → New gesture detection
   • OK Gesture → New gesture detection
   • Thumbs Up → New gesture detection

3. MONITOR PERFORMANCE:
   • Top-right FPS counter shows real-time frame rate
   • Color changes: Green (>30fps), Yellow (20-30fps), Red (<20fps)
   • Hand status indicators show detection state
